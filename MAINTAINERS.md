# Maintainers

This file lists the maintainers of the `redhat.argocd` Ansible collection.

## Current Maintainers

| Name | GitHub | Role |
|------|--------|------|
| Red Hat Ansible Team | [@redhat](https://github.com/redhat) | Lead maintainer |

## Responsibilities

Maintainers are responsible for:

- Reviewing and merging pull requests
- Triaging issues
- Releasing new versions to Ansible Galaxy
- Ensuring CI passes on all supported platforms
- Maintaining documentation and changelog

## Becoming a Maintainer

Regular contributors who demonstrate sustained engagement may be invited to
become maintainers. Reach out to the current maintainers if you are interested.
